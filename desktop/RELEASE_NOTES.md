# Pdf2zh Studio V1.0.0

首个正式 Windows 安装版。

## 主要功能

- 导入本地 GGUF 模型，通过 llama.cpp 在本机完成 PDF 翻译。
- 优先使用 CUDA，CUDA 不可用或启动失败时自动切换 CPU。
- 保留论文公式、图表、段落和页面排版。
- 支持扫描件 OCR、页面范围裁切、表格结构保护和多种输出格式。
- 大型文档按 BabelDOC 页数分块处理，默认每 50 页一段并自动合并。
- 模型加载和翻译任务在独立进程中运行，界面保持响应。

## 安装

下载 `Pdf2zhStudio-Setup-1.0.0-x64.exe` 后直接运行。安装程序默认安装到当前用户目录，不需要系统 Python。

## 系统要求

- Windows 10/11 x64
- NVIDIA 显卡可获得 CUDA 加速；没有可用 CUDA 时会自动使用 CPU
- 7B/8B 模型建议至少 8 GB 可用内存，更大模型需要更多内存或显存

## 已知说明

- 扫描件 OCR 在 CPU 上运行，页数较多时速度会明显变慢。
- CPU 推理可以正常使用，但性能低于 CUDA。
- 第三方模型的质量和许可证由模型提供方决定。
